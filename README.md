# Suhani Bhati — Portfolio

A modern, responsive personal portfolio website built with **React.js, Tailwind CSS, and Vite**. It showcases my technical skills, projects, education, experience, and core strengths as a Computer Science and Data Science undergraduate.

## ✨ Features

* Responsive single-page portfolio
* Modern dark-themed UI with hexagonal background design
* Dynamic hero section
* About Me section
* Core Strengths
* Experience
* Personal Projects
* Technical Skills
* Education
* Dark/Light theme toggle
* Responsive navigation
* Reusable React components
* Centralized portfolio content management

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Language:** JavaScript (JSX)
* **Package Manager:** npm

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/SuhaniBhati/portfolio.git
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

The production files will be generated in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## 📁 Project Structure

```text
src/
├── components/
│   ├── Navbar
│   ├── Hero
│   ├── About
│   ├── CoreStrengths
│   ├── Experience
│   ├── Projects
│   ├── ProjectCard
│   ├── Skills
│   ├── Education
│   ├── Footer
│   └── ThemeToggle
│
├── data/
│   └── portfolioData.js
│
├── App.jsx
└── index.css
```

### Architecture

* **`components/`** — Reusable UI components for each portfolio section.
* **`data/portfolioData.js`** — Centralized portfolio content and links, serving as the single source of truth.
* **`App.jsx`** — Controls the page structure, section order, and theme state.
* **`index.css`** — Contains global styles, design tokens, hexagonal background effects, cards, badges, and button styles.
